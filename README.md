**Нагрузочные проверки:** отключены по просьбе пользователя. Автоматизация приостановлена; запуск 300 студентов не входит в перенос 16.10.2026 и без отдельной команды не выполняется.

**Потоки:** создание по нумерованному списку ФИО или выбором существующих студентов, до 50 человек; индивидуальный и массовый сброс паролей. В каждом назначении задаётся собственная длительность. Сервер допускает максимум 50 активных непросроченных попыток и отклоняет ответы после срока. Пошаговая инструкция: [docs/FLOWS.md](docs/FLOWS.md).

**Git и обслуживание:** https://github.com/Denzel-is/finacademy.kz. Автокоммиты отключены по указанию владельца. CI проверяет изменения; данные и секреты исключены. [Выдача доступов и обслуживание](docs/OPERATIONS.md).

## Как запустить тест на сайте

**Администратор:** откройте «Тесты» и нажмите «Пройти тест» на карточке. Откроется пробное прохождение со случайной выборкой и оценкой. Оно не расходует попытки студентов и не записывается в учебные результаты.

**Студент:** войдите под своим ФИО с выданным временным паролем и задайте личный пароль. Откройте «Мои тесты», выберите назначенный тест и нажмите «Начать тест» → «Начать попытку». Если включён обязательный полный экран, браузер потребует отдельное нажатие. После обновления страницы используйте «Продолжить тест» на карточке.

**Выдать доступ:** администратор открывает «Назначения», выбирает опубликованный тест и поток либо студентов, указывает длительность в минутах и период доступа. Черновик сначала нужно наполнить вопросами и опубликовать.

## Что работает

- Вход по логину и паролю, HttpOnly-сессии, ограничения входа, блокировка студентов, сброс паролей, смена собственного пароля. Главный администратор создаёт сотрудников.
- Обзор с реальной статистикой, диаграммой, быстрыми действиями и последними попытками.
- Студенты: поиск, фильтры с сохранением при переходах, страницы, массовый выбор и перенос между группами, редактирование, экспорт Excel.
- Группы: создание, редактирование, состав и назначение тестов.
- Excel-импорт студентов: шаблон, предпросмотр, ошибки по строкам, пропуск существующих / обновление ФИО и группы без смены пароля, автоматическое создание групп, одноразовая выдача новых паролей и отчёт. До 500 строк за операцию.
- Конструктор тестов: дисциплина, описание, время, случайная выборка, порог, попытки, публикация, прокторинг, видимость результата и истории.
- Банк вопросов: создание и редактирование, 2–10 вариантов, один правильный, архив, поиск, Excel-шаблон и импорт с защитой от дубликатов. Снимки начатых попыток не меняются вслед за банком.
- Групповые и индивидуальные назначения, даты доступа, общий лимит попыток, закрытие новых запусков, назначение по списку логинов Excel. Повторное назначение обновляет доступ. Индивидуальное открытое назначение имеет приоритет над групповым.
- Кабинет студента: назначенные тесты, продолжение своей попытки, навигация, отметки вопросов, таймер, история, итог и PDF.
- Ответы: немедленный локальный кеш с привязкой к аккаунту и попытке; пакетная синхронизация каждые 15–19 секунд с разбросом; монотонные версии; восстановление при повторном входе; одна управляющая вкладка; финальное подтверждение только сервером.
- Серверная случайная выборка, сохранение порядка вопросов и вариантов, отсутствие ключа ответов в студенческом API, проверка владельца каждого запроса, атомарный запуск и идемпотентное завершение.
- Прокторинг на основе CenterTest: общий эпизод для blur/hidden/fullscreen, устойчивые идентификаторы, очередь, дедупликация в базе, длительность ухода, технические события обновления и потери сети, журнал у администратора. Режимы: off/log/warn/block; по умолчанию warn.
- Результаты: фильтры по тесту, группе и статусу, подробности попытки и ответов, журнал прокторинга, Excel и серверный PDF с кириллицей.
- Журнал административных действий, настройки организации с применением часового пояса к датам и PDF, адаптивная вёрстка.

## Запуск

Требуется Node.js 24+. Docker для текущей Cloudflare-версии не нужен.

```powershell
npm ci
npm run build
npm run db:local
npm run seed:local
npm run dev
```

Интерфейс: `http://127.0.0.1:5173`; локальный Worker API: `http://127.0.0.1:8787`.

Seed предназначен для инициализации демонстрационной базы. При повторном запуске уже существующие учётные записи не меняют пароль. Сохраните `.local/seed-state.json` локально; не загружайте его в репозиторий или хостинг.

## Проверки


`npm test`: точность порога, соль и проверка пароля, права, отсутствие ключа ответов, уникальная случайная выборка, неизменяемый снимок, продолжение, версии, конфликт вкладок, дедупликация событий, блокировка, лимит попыток, идемпотентное завершение, отклонение поздних ответов и повторный импорт.

## Перед переходом на VPS в Казахстане

Смотрите `docs/ROADMAP.md` и `docs/CENTERTEST-AUDIT.md`. Перед эксплуатацией на VPS нужны перенос в PostgreSQL, резервирование вне сервера и инфраструктурный мониторинг. Часовая проверка 300 студентов на Cloudflare выполняется в текущей задаче; после переноса её нужно повторить. Соответствие требованиям размещения в РК на текущем Cloudflare-стенде не заявляется.

Фронтенд React/TypeScript/Vite; API Hono/TypeScript с Web Request/Response; Cloudflare Workers Assets + D1. Схема находится в `migrations`, публичные контракты в `shared`, проверка тестов в `worker/exam.ts`. При переносе адаптируются D1-запросы, JSON-операции и пакетные транзакции, а интерфейс и правила оценки сохраняются.

## Исторические проверки Cloudflare (не текущая конфигурация)

С 16.10.2026 приложение работает на VPS, действующий предел — 50 активных попыток. Приведённые далее данные относятся к прежнему стенду. Генератор и автоматизация остановлены по указанию владельца; команды из этого раздела без новой явной команды пользователя не запускать. Часовая нагрузка на новом VPS не проверялась.

На Cloudflare создана отдельная нагрузочная группа с 300 вымышленными студентами `load001`–`load300`. Вместе с первоначальными 24 студентами в базе 324 аккаунта. Группе назначен отдельный технический тест. Доступы хранятся в `.local/load-access.csv`; пароли не публикуются.

```powershell
npm run load:prepare
npm run load:run
# Часовой сценарий при необходимости:
$env:DURATION_SECONDS='3600'
npm run load:run
```

`load:run` по умолчанию проводит трёхминутный прогон 300 отдельных HTTP-сессий. Проверяет массовый запуск, подтверждённые сервером 300 активных попыток, пакетное сохранение каждые 15–19 секунд, восстановление, дубликаты событий, массовое завершение и правильность всех 300 результатов. Результаты и фактические задержки: `output/load/latest.md` и `output/load/latest.json`. Сетевые сбои и 5xx повторно отправляются максимум три раза; каждый исходный сбой и восстановленная операция отдельно учитываются в отчёте. Полноценный часовой тест из ТЗ остаётся отдельной проверкой.

Исходный трёхминутный прогон: **300/300**, 3000 подтверждённых ответов, 5441 запрос, 0 ошибок, 180 секунд активной работы. Функциональная проверка пройдена; p95 менее 2 секунд не достигнут (старт 3189 мс, сохранение 4284 мс, завершение 3238 мс). Последующие короткие прогоны и прерванный часовой описаны в `docs/LOAD-TEST.md`. Подтверждения часовой нагрузки эти результаты не дают.

В «Обзоре» лёгкий счётчик активных студентов обновляется каждые 10 секунд по покрывающему индексу `status/deadline`. Полная статистика обновляется раз в минуту, без пересчёта всей истории каждые 10 секунд. Завершённые технические попытки доступны в «Результатах» с фильтром по нагрузочному тесту или группе.

### Текущее ограничение проверки 12.10.2026

Полный час **не подтверждён**. В локальном часовом прогоне первые 10 минут 300 сессий работали без ошибок, затем возникли массовые ECONNRESET/ENOTFOUND. Прогон остановлен, его технические попытки завершены с серверными ответами. Для автономного испытания подготовлен отдельный Worker `finance-academy-load`: 300 изолированных HTTP-сессий, 30 долговечных планировщиков, контроль раз в минуту и отчёты KV. Облачный контрольный запуск одного студента завершён: 25/25 ответов, 12 запросов без ошибок, правильная оценка и административная сверка.

При подготовке 300 облачных сессий приложение получило подтверждённую ошибку D1: **исчерпан общий суточный лимит бесплатного аккаунта на чтение строк**. Генератор остановлен (`LOAD_PAUSED=1`, cron отключён). До сброса лимита в 00:00 UTC или подключения Workers Paid запросы к базе временно недоступны. Платная подписка автоматически не подключалась. Новый прогон требует отдельного запуска после восстановления лимита. Инструкции и границы проверки: `docs/LOAD-TEST.md`. Успех одиночного прогона не означает прохождение часа на 300 студентов.

Оптимизации `perf-20261012-5`: атомарные запуск/сохранение/idle heartbeat, компактный ответ без повторной передачи вопросов, индекс истечения сессий, размещение Worker рядом с D1, лёгкий активный счётчик и корректная ошибка 503 при исчерпании квоты. Сборка и 7 автоматических проверок пройдены. Версия публикации: `51411884-865d-4f6a-871a-a095b44ad7f3`.

Порядок восстановления и остановки: `docs/LOAD-RETRY.md`. Для пробуждения локального Codex компьютер и приложение должны быть включены.
