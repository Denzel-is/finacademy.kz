# Потоки и доступ студентов

Сайт: https://finacademy.kz. Два администратора имеют одинаковые права; рабочие доступы хранятся отдельно в приватном `.local` и не публикуются в Git.

## Создание потока

1. Откройте «Потоки» → «Создать поток» и укажите название.
2. Вставьте список: каждое ФИО с новой строки. Поддерживаются номера с точкой, скобкой, двоеточием, знаком № и список без номеров. Например:

   ```text
   1: Иванова Анна Сергеевна
   2. Әбілова Айдана Ерланқызы
   3) Петров Иван
   ```

3. При необходимости выберите существующих студентов. В потоке может быть до 50 человек.
4. Нажмите «Проверить список». Исправьте отмеченные ошибки и повторы; затем нажмите «Создать поток».
5. В том же мастере назначьте нужные тесты. Скачайте Excel, скопируйте доступ конкретного студента или распечатайте карточки. Передайте каждому только его данные.

Логин — полное ФИО, временный пароль — **уникальный случайный для каждого студента**. Регистр букв и лишние пробелы при входе не мешают. Два одинаковых ФИО требуют уточнения имени; система не создаёт неоднозначные логины.

У студента один текущий поток. При выборе существующего студента он переводится в новый поток: логин становится ФИО, выдаётся новый уникальный временный пароль, прежние сессии закрываются. История результатов сохраняется с названием потока на момент попытки. Форма заранее сообщает об этом. Повторная отправка того же запроса создания не создаёт дубликатов и не сбрасывает уже изменённый пароль повторно.

## Вход и пароли

Перед доступом к тестам студент обязан заменить временный пароль своим, длиной не менее 10 символов. Позже пароль можно изменить кнопкой «Изменить пароль» в кабинете.

Если пароль забыт, откройте «Студенты». Для одного человека используйте сброс в его строке; для нескольких отметьте строки и нажмите «Сбросить пароли». После подтверждения каждый выбранный студент получит **новый уникальный временный пароль**, действующие сессии закроются. Следующий вход снова потребует смены пароля. Пароли других студентов не меняются.

## Назначение теста и время

В «Назначениях» выберите опубликованный тест и поток или отдельных студентов. Укажите длительность **от 1 до 240 минут**, число попыток и при необходимости период доступа. Для каждого назначения можно задать свою длительность; изменение назначения влияет на новые попытки. Уже начавшаяся попытка сохраняет свой исходный срок.

Даты начала и окончания вводятся в часовом поясе организации, который показан в форме (по умолчанию `Asia/Almaty`). Часовой пояс компьютера администратора не влияет на расписание.

## Сохранение и восстановление

Ответ сохраняется на устройстве сразу, отправляется примерно через 2–3 секунды, в последние 20 секунд — без задержки. Статус «Все ответы сохранены» означает подтверждение сервера. Пустое продление соединения выполняется каждые 30–35 секунд, изменения ответов не ждут этого интервала.

Открытие другой вкладки не перехватывает тест автоматически. Явное подключение переносит управление; при разных локальных и серверных ответах студент выбирает вариант в окне сравнения. Выход из аккаунта ожидает сохранения.

Если время закончилось до восстановления интернета, поздние ответы не засчитываются. На странице результата будет предупреждение и кнопка «Скачать копию» для локальных неподтверждённых ответов. Содержимое такой копии администратор рассматривает вручную; она не меняет оценку автоматически.

Срок попытки равен времени старта плюс указанная длительность, но не позже конца периода доступа. После срока сервер отклоняет новые ответы, закрывает попытку и считает результат по ответам, которые успел подтвердить. Обновление страницы и изменение часов компьютера не продлевают срок. Автоматическая обработка просроченных попыток выполняется сервером каждые 30 секунд.

Доступны четыре учебных банка: «Тесты МСФО 210 (RU)», «Тесты МСФО 210 (KZ)», «Тесты МСФООС 210 (RU)», «Тесты МСФООС 210 (KZ)». В каждом по 200 вопросов, случайная выборка 25, максимальный балл 100, проходной балл 50, исходная длительность 60 минут. Новые банки МСФООС не назначаются потокам автоматически.

Во всей платформе одновременно допускается не более **50 активных непросроченных попыток**. Если места заняты, следующий студент получает понятное сообщение и может начать после освобождения места. Возобновление своей активной попытки доступно. Это ограничение проверено функционально; нагрузочный прогон 50 студентов по просьбе владельца не запускался.

Подробнее о быстрой выдаче и повторном сбросе: [OPERATIONS.md](OPERATIONS.md).
