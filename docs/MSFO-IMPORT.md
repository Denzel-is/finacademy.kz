# Первые банки МСФО RU / KZ

Источник: `Тесты МСФО 210 (RU и KZ).docx`, передан заказчиком 12.10.2026. Несмотря на 210 в названии, таблица содержит номера 1–200 и по четыре варианта на двух языках.

Созданы «Тесты МСФО 210 (RU)» и «Тесты МСФО 210 (KZ)». В новой попытке сервер выбирает 25 уникальных вопросов, перемешивает варианты и фиксирует снимок. Время — 60 минут. Оценка нормирована к 100: каждый правильный ответ даёт 4 балла, порог — 50. Поэтому 12 правильных — 48 / не сдал, 13 — 52 / сдал. Штрафа за ошибку нет.

В Word 199 вопросов имеют отметку `1` в колонке правильного ответа; одна отметка относится одновременно к RU/KZ. У №188 (первоначальная стоимость сельхозмашины) отметка отсутствовала. 12.10.2026 пользователь явно подтвердил ответ **485 000**, первый вариант **A** в обоих языках. Подтверждение сохранено в приватном `.local/msfo/confirmed-keys.json`. Повторный импорт добавил ровно по одному вопросу; опубликованные банки содержат по **200 вопросов**, все тексты, варианты и ключи сверены через административный API. Исходный `pending.json` сохраняет информацию о пробеле в Word, а действующая сводка импорта больше не содержит неразрешённых ключей.

Оба теста назначены четырём демонстрационным группам FA, доступны студенческим аккаунтам и пробному прохождению администратора. Нагрузочная группа отделена. Использованы текущие настройки стенда: две попытки, предупреждающий прокторинг, без обязательного полного экрана, результат и история доступны. Эти дополнительные настройки не выдаются за требования заказчика.

Воспроизведение импорта:

1. Запустить `scripts/extract-msfo.py` с путём к исходному Word через bundled Python. Скрипт проверяет 200 номеров, четыре варианта, непустой текст обоих языков, уникальность и не более одного ключа. Сохраняет переносы строк, казахские символы и SHA-256 источника.
2. Запустить `node scripts/import-msfo.mjs`. Предпросмотр валидируется; импорт идемпотентен по содержимому. После записи проверяются все тексты, варианты, ключи и настройки через административный API.
3. Сохранить `.local/msfo/confirmed-keys.json`: для №188 указаны `option: "A"`, `confirmed_by: "user"` и текст явного подтверждения. Файл уже создан. Повторный запуск импорта идемпотентен и не добавляет дубликатов.

Исходные тексты, варианты, ключи и доступы хранятся в игнорируемой `.local/`, не включаются в публичные assets. Студенческий API получает только выбранные вопросы и варианты без ключа.

Сводка фактического импорта: `output/msfo/import.json`. Проверка порогов 48 / 52 / 100 включена в `tests/core.test.ts`.

Ранее пользователь просил временно оставить 199; последующее подтверждение ответа №188 заменило это условие. Учебный лимит остаётся 60 минут.

## Проверка на опубликованном стенде

`node scripts/verify-msfo.mjs` выполнен для вымышленного `student024`: RU — 13 правильных, 52 балла, зачёт; KZ — 12 правильных, 48 баллов, незачёт. В обеих попытках проверены 25 уникальных вопросов из соответствующего банка, отсутствие ключей в студенческом API, срок ровно 3600 секунд, сохранение всех 25 ответов, восстановление неизменного снимка, совпадение оценки с административной записью, неизменность результата и времени после повторного завершения. Сводка — `output/msfo/verification.json`.

Оба PDF скачаны с Cloudflare, извлечённый текст проверен, каждая страница отрисована и просмотрена: баллы 52/100 и 48/100, порог 50/100, правильные статусы, кириллица без наложений. Пробное прохождение KZ проверено в браузере: казахские буквы, выбор ответа, переход, прогресс и оценка 4/100 за один верный ответ. Сборка и четыре комплексных автоматизированных теста пройдены.
