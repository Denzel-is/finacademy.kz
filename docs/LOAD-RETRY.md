## Запуск

```powershell
node scripts/cloud-load/bootstrap.mjs
npx wrangler secret bulk .local/cloud-bootstrap-secrets.json --config scripts/cloud-load/wrangler.jsonc
```

Затем изменить только `vars.LOAD_PAUSED` на `"0"` в `scripts/cloud-load/wrangler.jsonc`, оставить `triggers.crons=[]`, опубликовать:

```powershell
npx wrangler deploy --config scripts/cloud-load/wrangler.jsonc
node scripts/cloud-load/trigger.mjs
node scripts/cloud-load/pull.mjs
```
